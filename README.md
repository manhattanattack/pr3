# Практическая работа №3 — PvP в Unity

Продолжение [практической №2](https://github.com/manhattanattack/pr2). Перенесено из ветки `pr3`; всё находится в `main` этого отдельного репозитория.

**Unity:** 6000.4.6f1. **Сервер:** Node.js + WebSocket (`ws`).

## Как запустить

1. Склонируйте проект (после переноса Git LFS ресурсов, см. ниже) и откройте папку проекта в Unity Hub.
2. Дождитесь компиляции и в меню Unity выберите **Tools → PR3 → Собрать боевую сцену**. Инструмент создаёт UI, префаб оружия, снаряд и связывает ссылки.
3. Убедитесь, что в Console нет красных ошибок.
4. Из папки `Assets/MazeServer` запустите `npm install` и `node server.js`.
5. Запустите `LobbyScene`, подключите два клиента к серверу и проверьте PvP.

Управление: **ЛКМ** — ближний удар (25 HP), **ПКМ** — снаряд (20 HP). После смерти — 3 секунды до возрождения со 100 HP.

Полный чек-лист — [README_PR3.md](README_PR3.md).

## Важно: ресурсы Git LFS

В исходной второй практической некоторые `.png` и `.ttf` хранились в **Git LFS**. Перенос кода и истории файлов через API GitHub **не перенёс содержимое LFS-объектов**. Чтобы спрайты и шрифты в новом репозитории не оказались пустыми LFS-указателями, один раз перенесите LFS-объекты на своём ПК:

```bash
git clone https://github.com/manhattanattack/pr2.git pr2-lfs
cd pr2-lfs
git lfs install
git lfs fetch --all origin
git remote add pr3 https://github.com/manhattanattack/pr3.git
git lfs push --all pr3
```

Для записи в `pr3` GitHub может запросить авторизацию. После этого клонируйте `pr3` обычным способом (`git clone https://github.com/manhattanattack/pr3.git`).

**Не считайте проект протестированным до запуска в Unity:** скрипты и данные подготовлены, но редактор Unity и две игровые сессии здесь не запускались.
